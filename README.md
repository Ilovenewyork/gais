Hello, welcome to GAIS!

GAIS is an application that allows you to control your computer using your eyes.

To set up gais on your computer, please run either `setup.sh` (Unix) or `setup.bat` (Windows)

To run gais locally on your computer, please run `npm start`

To build the distributable gais application on your computer, please run either `build.sh` (Unix) or `build.bat` (Windows)
